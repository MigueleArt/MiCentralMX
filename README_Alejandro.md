# MiCentralMX

MiCentralMX es un sistema para administrar las operaciones básicas de un negocio.

## Funciones principales

- Gestión de productos y categorías.
- Control de inventario.
- Registro de compras y entradas de mercancía.
- Registro de ventas.
- Control de pagos, ingresos y egresos.
- Registro de mermas y ajustes.
- Funcionamiento sin conexión y sincronización de datos.

## Usuarios

El sistema contempla dos tipos de usuario:

- Administrador.
- Trabajador.

## Estado del proyecto

Proyecto en etapa de MVP (producto mínimo viable).
